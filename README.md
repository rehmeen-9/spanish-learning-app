# 🦜 Chispa — Learn Spanish with a Spark

A smart Spanish vocabulary learning app with spaced repetition, streaks, and progress tracking — built with React & TypeScript on Lovable.

🔗 **Live app:** [bunny-boost-dash.lovable.app](https://bunny-boost-dash.lovable.app)

## What it does
- Learn Spanish vocabulary with spaced repetition (half-life regression)
- Track your daily streaks and stay consistent
- View detailed progress reports by category
- Username-based — no account needed, progress saved in browser

## Tech Stack
- **Frontend:** React + TypeScript
- **Styling:** Tailwind CSS
- **Built with:** Lovable (AI-powered app builder)
- **Deployed:** Lovable hosting

## How to Use
1. Go to [bunny-boost-dash.lovable.app](https://bunny-boost-dash.lovable.app)
2. Enter a username to get started
3. Practice Spanish words and build your streak!
